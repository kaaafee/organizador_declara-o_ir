# organizador_declara-o_ir

# 📊 Agregador de Dados para Declaração de Imposto de Renda no Excel

Este repositório contém o projeto prático desenvolvido para o desafio da **DIO (Digital Innovation One)**. O objetivo principal foi criar uma ferramenta robusta e intuitiva no Excel para organizar, reunir e validar todas as informações essenciais necessárias para a declaração de imposto de renda de forma eficiente.

---

## 🚀 Sobre o Projeto

Gerenciar dados financeiros e documentos para o Imposto de Renda pode ser uma tarefa complexa. Para solucionar isso, esta ferramenta foi desenvolvida servindo como um **agregador de dados centralizado**, permitindo que o usuário controle suas entradas com segurança, agilidade e uma experiência de navegação simplificada.

---

## 🛠️ Funcionalidades e Recursos Utilizados

A planilha foi construída aplicando conceitos avançados do Excel, garantindo tanto a automação quanto a usabilidade:

* **🧭 Menus de Navegação:** Interface amigável com botões e links rápidos para transitar facilmente entre as diferentes abas e seções da ferramenta.
* **🔒 Validação de Dados:** Regras automáticas aplicadas nas células para evitar erros de digitação e garantir a integridade dos registros financeiros.
* **📈 Organização de Entradas:** Estruturas organizadas para categorizar receitas, despesas e dados fundamentais para a declaração.
* **🔗 Links Rápidos e Atalhos:** Facilidade de acesso a informações e documentos complementares diretamente pela planilha.

---

## 📚 O que foi Praticado

Este desafio permitiu consolidar e aplicar os seguintes conhecimentos abordados nas aulas:
* Criação de interfaces funcionais e profissionais no Excel.
* Aplicação de validações de dados para controle de qualidade das entradas.
* Técnicas de usabilidade (User Experience) aplicadas a planilhas de controle financeiro.
